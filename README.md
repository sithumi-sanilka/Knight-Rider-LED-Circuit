# Knight Rider LED Chaser Circuit

A classic sequential LED flasher circuit (Knight Rider style) built using a 555 Timer and a CD4017 Decade Counter. This repository contains the functional simulation as well as PCB design files.

## Project Structure
* `/Simulation`: Contains the Proteus simulation file to test circuit logic and timing.
* `/Hardware`: Contains the EasyEDA schematic and layout files and PCB design file.

## How to Use
1. Clone or download this repository.
2. Open the `.pdsprj` file in Proteus to run the interactive simulation.
3. Import the hardware files into EasyEDA to modify the schematic or board layout.
